# Shanmukh's Portfolio

Personal portfolio of Shanmukh Sai Venkat Pinchingula, a Java Full Stack developer (Spring Boot, microservices, React, Docker).

A single static page, `index.html`, with no build step and no dependencies.

## Features
- Project cards with a technology filter and expandable architecture notes
- Step-by-step walkthroughs of the gateway request, JWT login and layered backend
- Job description fit checker that compares a posting with my stack
- Interactive terminal (`help`, `skills`, `projects`, `contact`)
- Interview Q&A cards
- Interview and assessment scheduler that converts times to IST
- Light and dark themes

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
Repository Settings, then Pages, then deploy from the `main` branch, root folder.
