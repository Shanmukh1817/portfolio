CompleteMicroservices

E-Commerce Microservices Platform

An e-commerce backend made of four independently deployable Spring Boot services: service registry, API gateway, product and order. Netflix Eureka handles discovery and Spring Cloud Gateway routes every request from one entry point.

  • Java
  • Spring Boot
  • Spring Cloud
  • Eureka
  • OpenFeign
  • Docker
Architecture and decisions
  • Split by responsibility. Registry, gateway, product and order run as separate services, so each can be deployed on its own.
  • One front door. Spring Cloud Gateway gives clients a single address and centralises routing.
  • Service-to-service calls. The order service calls the product service through OpenFeign to validate stock and pricing.
  • Layered code. Each service uses controller, service and repository layers with centralised exception handling, on Spring Data JPA and Hibernate.
  • Build. One multi-module Maven project.

Student Course Management System

Under the hood

How my projects work, step by step

  1. Client calls the gateway

    Every request enters through Spring Cloud Gateway, so clients know one address.

  2. Gateway finds the service

    Services register with the Netflix Eureka registry, and the gateway uses it to discover where they run.

  3. Request reaches the order service

    The gateway routes it to the right Spring Boot service, which handles it in its controller, service and repository layers.

  4. Order calls product over OpenFeign

    The order service validates stock and pricing by calling the product service through an OpenFeign client.

  5. Response returns the same way

    Errors are handled in one place, so a failed check comes back as a clear error response.

  1. User signs in

    The React front end sends the credentials to the Spring Boot API.

  2. Password is checked

    Spring Security compares the password with its BCrypt hash. Plain passwords are never stored.

  3. API issues a JWT

    On success the API returns a signed token that identifies the user.

  4. Axios sends the token

    The front end attaches the token to its API calls, and protected routes keep signed-out users away from the board.

  5. Server stays stateless

    Each request is verified from its token, so the server keeps no session between calls.

  6. Ownership is checked

    The data layer enforces per-user ownership, so people only see their own projects and tasks.

      Interview prep

      Ask me about my projects

      MicroservicesWhy did you split the e-commerce backend into services?

      To practise real service boundaries. Registry, gateway, product and order are separate Spring Boot services that deploy independently. Eureka handles discovery, and Spring Cloud Gateway gives clients a single entry point.

      MicroservicesHow do your services talk to each other?

      The order service calls the product service through OpenFeign to validate stock and pricing. Feign turns the call into a declared Java interface, and Eureka tells it where the product service is running.

      SecurityHow does authentication work in TaskFlow?

      Stateless JWT with Spring Security. Passwords are hashed with BCrypt, the React app sends the token on each request, and the data layer checks that a user owns the project or task they ask for.

      SecurityHow did you handle roles in the Student Course system?

      Spring Security enforces two roles, ADMIN and STUDENT, on the API. Request bodies are checked with Bean Validation, and Swagger documents the endpoints.

      DataHow did you model relationships between students and courses?

      With Spring Data JPA and Hibernate. Students, courses and enrollments use one-to-many and many-to-many mappings, and Hibernate generates the schema in MySQL.

      TestingHow do you test your code?

      I wrote repository layer tests with JUnit and @DataJpaTest in the Student Course project. They run against the JPA layer without starting the whole application.

      DeploymentHow do you ship an app?

      A multi-stage Dockerfile builds a small image, and Docker Compose runs the app with its database. I deployed Student Course Management to Render's free tier this way.

      ExperienceWhat did you do at V Square Tech?

      I was a Java Full Stack Development intern from Jan to May 2024. I built responsive web features, developed and debugged RESTful APIs, and connected front-end screens to the back end while working with senior engineers on code review.
